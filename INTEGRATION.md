## Optimization review

The frontend branch already preserves these main-branch optimizations:

- Paired Merkle insertion with `append_pair`, including one history root per
  completed instruction and the hoisted zero-hash table.
- Raw-byte BN254 arithmetic on chain; arkworks remains in host tests and the
  off-chain prover, not the deployed program's normal dependencies.
- Stack buffers and SHA-256 `hashv`, compile-time singleton PDAs, compact Merkle
  state and compressed encrypted notes.

Integration fixes:

- Restore one shared `Rent::get()` in initialization instead of three reads.
- Keep SDK note synchronization incremental. Full local-store recovery is now
  explicit with `syncUtxos({ recoverMissing: true })`.
- Make the backend's repeated RPC history polling opt-in with
  `INDEXER_RPC_FALLBACK=true`; `run.sh` enables it for local Surfpool.

The 64-account entrypoint is retained because the new swap path needs more than
the previous 16-account limit.
